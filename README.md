# Local Business Review Analyzer

## Overview

Local Business Review Analyzer is a web-based tool that helps local businesses understand customer feedback.

Instead of manually reading many customer reviews, the system analyzes the reviews and presents important business insights through a simple dashboard.

## Problem Statement

Local businesses receive customer reviews on platforms such as Google and Yelp. However, manually analyzing a large number of reviews can be time-consuming.

Business owners need a simple way to understand:

- What customers like
- What customers dislike
- Which business areas need attention
- What actions can be taken to improve customer experience

## Proposed Solution

LBR Insight Engine analyzes customer reviews using sentiment analysis and topic detection.

The system identifies:

- Positive sentiment
- Negative sentiment
- Neutral sentiment
- Top positive trends
- Top negative issues
- Important business topics
- Actionable recommendations

## Key Features

- Customer review analysis
- Sentiment classification
- Business topic detection
- Top 3 positive trends
- Top 3 negative issues
- Review Intelligence Map
- AI Strategist recommendations
- Interactive Streamlit dashboard

## Technology Stack

- Python
- Streamlit
- NLTK VADER
- Plotly
- Pandas
